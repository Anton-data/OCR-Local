# Политика безопасности

Не публикуйте конфиденциальные документы, токены и сведения о найденных уязвимостях в открытых issue.

Сообщение о проблеме должно содержать:

- тип проблемы;
- затронутый компонент;
- условия воспроизведения;
- минимальные шаги воспроизведения;
- оценку возможного воздействия.

Не прикладывайте реальные пользовательские документы и секреты. Для проверки используйте обезличенный минимальный пример.
