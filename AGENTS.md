# Рабочие инструкции

- Общаться с пользователем на русском языке.
- Не передавать пользовательские документы во внешние сервисы без явного разрешения.
- Перед изменением структуры проекта проверять текущий статус Git и сохранять только относящиеся к задаче изменения.
- После изменений выполнять доступные проверки и фиксировать результат в отчёте.
- Не добавлять в репозиторий секреты, токены, пароли, временные файлы, кэши, модели и пользовательские документы.
- Все новые требования и решения документировать в текстовых файлах Markdown.
