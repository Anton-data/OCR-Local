# Рабочие инструкции

- Общаться с пользователем на русском языке.
- Не передавать пользовательские документы во внешние сервисы без явного разрешения.
- Перед изменением структуры проекта проверять статус Git и сохранять только относящиеся к задаче изменения.
- После изменений выполнять доступные проверки запуска, API и базового сценария обработки.
- Не добавлять в репозиторий секреты, токены, пароли, временные файлы, кэши, модели и пользовательские документы.
- Новые требования и решения документировать в Markdown.
- При изменении интерфейса проверять русский язык, светлую и тёмную темы, загрузку файла и экспорт результата.
