# Технические правила OCR-Local

## Окружение

- Основная среда разработки — Windows 10/11 и Docker Desktop/WSL2.
- Для GPU используется NVIDIA Container Toolkit; CPU-режим должен оставаться рабочим fallback.
- Конфигурация запуска хранится в `docker/compose.dev.yaml` и связанных Dockerfile.
- Порты, переменные окружения и команды запуска должны быть описаны в `docker/DEV.md`.

## Архитектура

- Сохранять существующие API, CLI, графический интерфейс и экспортные форматы, если задача явно не требует их удаления.
- Изменения пользовательского интерфейса держать отдельно от логики обработки документов.
- Не изменять исходный файл пользователя; производные результаты сохранять в отдельном каталоге.
- Для поискового PDF сохранять текстовый слой и визуальный результат согласованными.

## Проверки

- Перед commit выполнять `git diff --check`.
- Для изменений Python запускать целевые тесты и проверку импорта изменённых модулей.
- Для Docker-изменений проверять сборку затронутого сервиса и его health endpoint.
- Не публиковать большие бинарные файлы и локальные результаты обработки.
