# Требования OCR-Local

## Функциональные требования

1. Принимать локальные PDF-файлы, изображения и поддерживаемые офисные документы.
2. Выполнять распознавание в локальном окружении.
3. Сохранять исходный файл без изменений.
4. Формировать текстовый результат и сохранять его рядом с результатами обработки.
5. Показывать пользователю состояние операции и понятное сообщение об ошибке.
6. Поддерживать пакетную обработку и повторный экспорт результата.

## Нефункциональные требования

- пользовательские документы не отправляются во внешние API по умолчанию;
- обработка должна работать на CPU и использовать GPU при его наличии;
- установка зависимостей и запуск должны быть воспроизводимыми;
- временные файлы и кэши не попадают в Git;
- ошибки не должны приводить к потере исходных данных;
- изменения интерфейса проверяются в русском языке и в обеих темах.

## Правила публикации

- не добавлять секреты, токены, пароли, модели, кэши и реальные документы;
- не добавлять результаты OCR и файлы из `output/`;
- перед публикацией проверять `git diff --check`, тесты затронутых компонентов и состав коммита;
- инструкции и требования хранить в Markdown.
