# OCR-Local

Локальный проект для OCR и обработки документов.

Репозиторий содержит только текстовые инструкции, требования и рабочие заметки. Исходный код, контейнеры, модели и тестовые документы будут добавляться отдельно после утверждения новой архитектуры.

## Назначение

- локальная обработка документов без обязательной передачи данных во внешние сервисы;
- распознавание текста и сохранение результата в удобном текстовом формате;
- поддержка воспроизводимой настройки окружения;
- возможность дальнейшего расширения без привязки к прежнему проекту.

## Статус

Проект находится на этапе подготовки требований. Реализация и структура каталогов будут определены после согласования технического задания.
