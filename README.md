# OCR-Local

Локальная система OCR и обработки документов.

В репозитории сохранена рабочая реализация обработки документов. Текущая ветка развития ориентирована на локальную эксплуатацию, русский интерфейс и сохранение пользовательских данных на компьютере.

## Основные возможности

- распознавание PDF и изображений;
- обработка офисных документов;
- формирование структурированного текстового результата;
- локальный API и графический интерфейс;
- поддержка CPU и GPU при наличии совместимого оборудования;
- экспорт результатов в текстовые и офисные форматы.
